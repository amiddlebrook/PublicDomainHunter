# Deploying FastAPI Backend to Cloudflare

## Option 1: Cloudflare Workers (Python Runtime - Beta)
Note: Limited support for FastAPI, no SQLAlchemy/Database support yet

```bash
# Deploy backend as separate worker
cd /home/user/PublicDomainHunter
npx wrangler deploy --config wrangler-backend.toml
```

## Option 2: Deploy Backend Separately and Use Cloudflare as Proxy
1. Deploy FastAPI to: Railway, Render, or Fly.io
2. Get backend URL (e.g., https://backend-xxx.railway.app)
3. Update wrangler.toml BACKEND_URL to point to it

## Option 3: Use Cloudflare D1 + Simplified Backend
Convert to use Cloudflare D1 instead of PostgreSQL

## Recommended: Use External Backend Service
Since your app uses PostgreSQL, SQLAlchemy, websockets - deploy backend externally

Quick Deploy to Railway:
```bash
# Install Railway CLI
npm install -g @railway/cli

# Deploy
railway login
railway init
railway up
```

This will give you a URL like: https://publicdomainhunter-production.up.railway.app
Then update wrangler.toml to use this URL.
